# 공부결 캐릭터 컬렉션

16개 유형에 서로 다른 동물 캐릭터를 연결했습니다. 모두 같은 입체 질감, 조명, 투명 배경을 사용합니다. 이름과 소개는 `src/lib/characters.ts`, 카드 앞·뒷면은 `src/components/character-card.tsx`에서 관리합니다.

## 제작 기록

- 도구: OpenAI 내장 ImageGen. Google Imagen 연결은 발견되지 않아, 사용자에게 대체 도구 사용을 알린 뒤 제작했습니다.
- 원본: `.artifacts/character-originals/*.png` (16장, 투명 배경, 로컬 보관)
- 서비스 이미지: `public/characters/*.webp` (768px 이내, 알파 보존)
- 분석 화면: `public/characters/thumbs/*.png` (192px)
- 공유 미리보기: `public/characters/share/*.png` (512px)
- 정확한 개별 생성 프롬프트: `art/characters/prompts.json`
- 동일한 아트 방향을 유지하기 위해 01번 루미를 나머지 15장 생성의 스타일 참조로 사용했습니다.
- 이미지 후처리는 크기 조절과 파일 형식 최적화만 수행했습니다. 글자와 카드 배경은 웹 UI에서 표시합니다.
