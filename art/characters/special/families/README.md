# 유형별 완성 기념 단체사진

내장 ImageGen으로 기존 네 캐릭터 이미지와 16명 단체사진을 참조해 유형별로 생성했다.
최종 프롬프트는 [prompts.json](./prompts.json)에 보관한다.

- 시각형: 루미·모아·루트·피코, 함께 펼친 개념 지도.
- 청각형: 소리·멜로·토크·리프, 이야기를 나누는 정원 벤치.
- 촉각형: 토리·몽·블록·조이, 블록과 종이접기를 만든 공작 테이블.
- 운동형: 페이스·바니·루카·스킵, 공부 중 잠시 쉬어 가는 학교 정원.

각 유형의 PNG(다운로드)와 WebP(quality 95, 웹 표시)를 1664 × 936의 정확한
16:9로 저장했다. 생성 원본 1672 × 941의 구도를 유지하며 소폭 축소했다.
각 사진의 캐릭터 수, 정체성, 의상 및 손·발 구성을 시각적으로 확인했다.

파일은 public 외부에 둔다. `/api/collection/special-card?family=visual` 등으로
요청하면 서버가 계정의 해당 유형 네 종 개봉 여부를 확인한 뒤 제공한다.
`&download=1`은 PNG 다운로드다. 유형별 완성은 기존 수집 기록에서 계산하므로
별도 보상 지급이나 DB 마이그레이션 없이 기존 완성 계정에도 적용된다.

도감에서는 해당 유형 필터를 선택했을 때만 네 캐릭터 뒤의 마지막 카드로 표시한다.
전체 도감은 기존 16명 스페셜 카드만 표시한다. PC에서는 두 카드 열을 차지하고,
모바일에서는 한 행 전체를 차지한다. 잠금 화면은 공개 캐릭터 썸네일을 CSS로
검게 처리한 실루엣과 물음표를 사용하며, 보호된 단체사진·영상은 요청하지 않는다.

## 8초 움직이는 단체사진

각 사진을 참조해 `gemini-omni-1.1-flash`로 한 번씩, 총 네 번 새로 생성했다.
처음부터 8초를 요청했으며 10초 영상을 자르거나 역재생한 결과가 아니다.
고정 카메라 아래 작은 고개 움직임·호흡·눈 깜빡임을 사용하고, 마지막 초에도
움직임이 이어지는 반복 연출을 지정했다. 소품 접촉과 네 캐릭터의 외형을 유지한다.

- 파일: `{visual,auditory,tactile,motion}-loop-8s-v1.mp4`.
- 사양: 1280 × 720, 16:9, 8초, 24fps, 192프레임, 무음 H.264/yuv420p/faststart.
- 프롬프트·사용량·파일 검사 기록: `motion/*.prompt.txt`, `motion/*.json`.
- [공식 요금](https://ai.google.dev/gemini-api/docs/pricing#gemini-omni-flash)과 응답
  토큰 사용량으로 계산한 총 예상 비용은 약 $3.31이다. 실제 청구 금액은 별도다.
- 원본과 검토 장면: `.artifacts/family-videos/{family}/`. 전체 프레임 디코딩,
  초별 움직임, 1초 간격 장면과 첫·마지막 프레임을 검토했다.
- 웹에서는 해당 유형 네 종을 개봉한 계정만 `&format=mp4`로 접근할 수 있다.
  Range 요청도 인증과 수집 검증 후 제공한다. `&format=mp4&download=1`은 영상 저장이다.
- 화면 안에서 무음 반복 재생하며, 확대창을 열면 뒤쪽 카드 영상은 멈춘다.
  동작 줄이기에서는 수동으로 재생하고, 영상 실패 시 원래 사진을 유지한다.
- 학생의 재생·저장은 생성 API를 호출하지 않는다.

검증: API 테스트 16개, desktop/mobile Chrome 단체사진·영상 E2E 6개,
타입 검사, 변경 파일 ESLint 및 프로덕션 빌드를 통과했다. 네 영상 각각을
브라우저에서 두 번 이상 반복 재생하고 정지·확대·다운로드를 확인했다.
동작 줄이기의 자동 요청 방지, 재생 실패 시 사진 유지, 비로그인·미완성
접근 차단 및 Range 206/416 응답을 확인했다. 실제 모바일 기기 검증은 별도다.
배포 파일 추적에 네 MP4가 모두 포함되는 것도 확인했다.

재현 명령:

```powershell
# 입력 준비만 수행 (유료 호출 없음)
node scripts/generate-family-videos.mjs --family=visual
# 새 요청만 허용. 기존 시도 기록이나 최종 영상이 있으면 중복 생성을 차단한다.
node scripts/generate-family-videos.mjs --family=visual --generate
# 저장된 원본 가공만 수행 (유료 호출 없음)
node scripts/prepare-family-videos.mjs --family=visual
# 계정 도감에 영향을 주지 않는 로컬 HTML 미리보기
node scripts/preview-family-videos.mjs
```
