# 도감 완성 스페셜 카드

16개 공부캐를 모두 수집하고 선물 개봉까지 완료한 계정에 열리는 기념 단체사진.

- 제작: 내장 ImageGen, 기존 16개 캐릭터 아트워크를 묶은 4개 참조 시트 사용.
- 최종 파일: `group-photo.png` (저장용), `group-photo.webp` (웹 표시용, quality 95).
- 최종 크기: 1664 × 936, 정확한 16:9. 생성 원본 1672 × 941을 전체 구도 유지하며 소폭 축소.
- 구도: 학교 정원에서 8명씩 두 줄, 16명 모두 얼굴·의상·소품을 확인할 수 있는 기념사진.
- 프롬프트: [prompt.txt](./prompt.txt).
- 서비스 접근: `/api/collection/special-card`에서 계정과 개봉한 16종을 서버에서 확인. 공개 public 경로에 두지 않는다.
- 다운로드: 같은 API에 `?download=1`을 붙이면 PNG 첨부 파일을 반환한다.
