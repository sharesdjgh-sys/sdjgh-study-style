# 서대전여고 이벤트 카드

사용자가 제공한 교표를 기존 소품과 의상에 적용한 이벤트 전용 이미지입니다. 기존 원본과 서비스 카드 카탈로그는 그대로 유지합니다.

| 컬렉션 | 최종 구성 | 미리보기 | 제작 기록 |
| --- | --- | --- | --- |
| 배지 카드 모아보기 | 최종 캐릭터 48장 + 단체 5장 | [배지 카드 전용 갤러리](../../../../ref/sdj-badge-cards-preview.html) | 캐릭터·종류 필터, 6장씩 보기 |
| 캐릭터 카드 | 16명 × 특별 2장·일상 1장 = 48장 | [전체 카드](../../../../ref/sdj-character-cards-preview.html) | [README](sdj-character-v2/README.md) |
| 단체 카드 | 16인 단체 1장 + 유형별 4인 단체 4장 = 5장 | [단체 카드](../../../../ref/sdj-school-cards-preview.html) | [README](sdj-school-v2/README.md) |
| 재선별 비교 | 수정한 12장의 전후 비교 | [비교·교표 확대](../../../../ref/sdj-character-cards-review.html) | [수정 이유](sdj-character-v2/review.json) |

최종 이미지 53장은 각각 PNG와 WebP를 제공합니다. 수정 전 비교에 필요한 캐릭터 이미지 12장만 `sdj-character-v2/before/`에 WebP로 별도 보관합니다. 채택하지 않은 단체 시안과 교체된 고용량 PNG, 중복 갤러리, 임시 검토 캡처는 정리했습니다.

HTML은 저장소의 상대 경로로 자산을 읽으므로 로컬 브라우저에서 바로 열 수 있습니다. PNG 열기 링크는 새 탭에서 이미지를 표시하며 브라우저의 이미지 저장 기능으로 저장할 수 있습니다. 미리보기와 제공받은 교표만 `ref`의 Git 제외 규칙에서 예외로 추적합니다.

제작 도구는 Built-in ImageGen입니다. 프롬프트·선정 사유·해상도·최종 경로는 각 컬렉션에 기록했습니다. WebP는 원래 해상도를 유지한 품질 95 형식 변환본입니다. 카드의 서비스 내 획득·이벤트 지급 기능은 이 변경에 포함하지 않습니다.
