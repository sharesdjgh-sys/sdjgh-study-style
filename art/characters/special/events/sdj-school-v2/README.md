# 서대전여고 이벤트 카드 v2

[HTML 미리보기 열기](../../../../../ref/sdj-school-cards-preview.html) — 파일을 브라우저에서 열면 카드 선택, 원본 비교, 확대 및 PNG 열기을 사용할 수 있습니다.

사용자가 지정한 `ref/서여고 로고.webp` 교표를 기존 소품에 작게 적용한 이벤트 전용 이미지입니다. 16인 단체사진 1종과 유형별 4인 단체사진 4종을 포함합니다.

원본 사진은 보존하고, 채택하지 않은 v1 시안은 정리했습니다. 일반 카드 보상이나 이벤트 지급 로직에는 연결하지 않았습니다.

| 이미지 | 교표 위치 | PNG | WebP |
| --- | --- | --- | --- |
| 16인 단체 | 왼쪽 앞줄 비버의 앞치마 주머니 자수 | [PNG](group-photo.png) | [WebP](group-photo.webp) |
| 시각형 4인 | 카멜레온의 가방 덮개 | [PNG](visual.png) | [WebP](visual.webp) |
| 청각형 4인 | 왼쪽 아래 초록색 배낭 | [PNG](auditory.png) | [WebP](auditory.webp) |
| 촉각형 4인 | 테이블 위 연필 머그컵 | [PNG](tactile.png) | [WebP](tactile.webp) |
| 운동형 4인 | 쿼카가 들고 있는 카드 | [PNG](motion.png) | [WebP](motion.webp) |

내장 ImageGen으로 각 원본과 지정 교표를 함께 참조하여 편집했습니다. 생성 편집 특성상 주변 세부 묘사에는 미세한 차이가 있습니다. PNG는 생성 결과 그대로 보관하고 WebP는 같은 해상도로 품질 95 인코딩했습니다.

최종 프롬프트: [prompts.json](prompts.json). 파일 정보: [manifest.json](manifest.json).
