# 16명 공부캐 — 8초 반복 영상

현재 16명 모두 **8초·24fps·192프레임·720×720·무음** 영상을 사용합니다. 기존 15개는 사용자 제안에 따라 처음 8초만 원래 속도로 유지하고 뒤의 약 2초 정지 구간을 제거했습니다. 재생 시간을 JavaScript로 강제로 되감는 방식이 아니라 MP4 자체를 편집했습니다. 파일명을 새로 부여해 이전 영상·포스터의 캐시를 피합니다.

모아·토리·바니는 8초 직전 자세 또는 배경색이 시작 장면과 조금 달라, 마지막 각각 6·10·12프레임 간격(0.25·0.42·0.5초)만 실제 첫 프레임으로 짧게 연결했습니다. 끝에 정지 프레임을 덧붙이거나 역재생하지 않았습니다. 다른 12개는 단순히 8초로 잘랐습니다. 이 편집에는 생성 API를 호출하지 않았고 **추가 생성 비용은 $0**입니다.

멜로는 [두 팔로 수정한 원본](../melo-anatomy-v2.json)을 사용해 **한 번의 새 유료 요청**으로 8초 영상을 제작했습니다. 헤드폰에 닿는 손과 플레이어를 든 손을 유지하고, 고개·호흡·꼬리의 작은 움직임이 마지막 초에도 이어지도록 설계했습니다. [정확한 새 프롬프트](melo-v2.prompt.txt), [사용량·가공 기록](eight-second-delivery/auditory-solo-flexible.json)을 보관합니다. 응답 토큰 기준 추가 예상 비용은 **$0.8288005(약 $0.83)**이며 실제 청구서 금액은 아닙니다. 이전의 세 팔 영상은 재생 목록에서 제외했습니다.

[현재 16개 파일과 가공 기록](collection-eight-second.json), [8초 버전 검증 기록](validation-eight-second.json)을 참고하세요. 이미지 수정 직후의 정적 화면 검사는 이전 단계의 기록입니다. 스페셜 단체사진은 기존 사진 카드입니다.

현재 버전은 전체 프레임 디코딩과 192프레임·8초·24fps·무음 형식을 확인했습니다. 마지막 1초의 프레임 간 변화도 검사해 제거했던 긴 정지 구간이 남지 않았는지 확인했습니다. 16개 동시 재생 검사에서 각 영상이 두 번 이상 반복됐고, 경계에서 표시된 프레임 사이 간격은 약 50~83ms였습니다. 이는 로컬 Chrome에서의 부하 검사 결과입니다. 멜로의 0~7초 장면과 시작·끝을 육안으로 검토해 두 팔·두 손과 소품 접촉이 유지되는 것을 확인했습니다. 데스크톱 22개·모바일 Chrome 화면 에뮬레이션 22개, 총 44개 브라우저 테스트와 타입 검사·변경 파일 ESLint·프로덕션 빌드가 통과했습니다.

저장된 영상으로 재현할 수 있습니다. 아래 편집·미리보기 명령에는 API 호출이 없습니다.

```powershell
node scripts/trim-character-loops.mjs
node scripts/trim-character-loops.mjs --code=auditory-solo-flexible
node scripts/preview-character-videos.mjs
# .artifacts/character-videos/review.html
```

멜로 생성은 별도 명령 `node scripts/generate-melo-video.mjs --generate`이며 기존 시도 기록이나 새 최종 파일이 있으면 추가 요청 전에 멈춥니다. 앱 실행·빌드·재생은 생성 명령을 호출하지 않습니다.

## 최초 10초 제작 기록

아래 내용은 8초 편집과 멜로 수정 이전의 이력입니다. 초기 프롬프트가 마지막 정지 자세를 지정해 실제 영상 대부분의 움직임이 약 8초 이후 줄었습니다. 처음·마지막 장면의 유사성과 파일 반복 재생 검사만으로 동작의 연속성을 보장할 수 없습니다. 당시 검사에서 놓친 멜로의 세 팔 오류는 원본부터 수정했습니다.

사용자가 루미의 10초 시안을 승인하고 나머지 캐릭터 제작을 요청해, Gemini Omni 1.1 Flash로 15명의 전용 영상을 추가했습니다. 루미는 승인된 v2 영상을 그대로 사용합니다. 스페셜 단체사진은 기존 사진 카드입니다.

## 제작과 비용

나머지 15명은 **각각 한 번**, 총 15회의 유료 요청으로 완성했습니다. 중복 생성·자동 재시도 없이 진행했고 추가 예상 비용은 응답 토큰 사용량 기준 **$15.4190265(약 $15.42)**입니다. 루미의 현재 10초 v2를 합한 전체 영상의 예상 생성 비용은 약 $16.45이며, 보존된 루미 4초 v1 시안의 비용은 별도입니다. 실제 Google 청구서를 확인한 값은 아닙니다. 요금 계산 근거는 [루미 상세 기록](README.md#제작과-비용)의 2026-10-01 Google 공식 요금입니다.

원본 영상은 1280×720이고, 카드용 파일은 중앙 720×720 영역을 추출한 **10초·24fps·240프레임** H.264/yuv420p MP4입니다. 오디오 트랙을 제거하고 faststart를 적용했습니다. 정적 대체 이미지는 각 영상의 실제 첫 프레임으로 만들었습니다. 원본 이미지와 영상, 요청 기록, 검토용 프레임은 `.artifacts/character-videos/{code}/`에 보관하며 Git에서는 제외합니다. 최종 MP4·WebP, 전송한 프롬프트와 비밀 값이 없는 생성 기록은 저장소에 포함합니다.

바니의 원본은 첫 장면과 마지막 장면 사이 배경색 차이가 보여, 마지막 약 0.96초의 휴식 자세를 실제 첫 프레임으로 서서히 연결했습니다. 10초 길이는 유지했고 역재생이나 추가 유료 생성은 하지 않았습니다. 이 보정은 `scripts/character-video-common.mjs`에 재현 가능하게 포함했습니다. 나머지 영상에는 이 연결 보정을 사용하지 않았습니다.

## 웹 적용과 검토

`CharacterCard`가 캐릭터 코드에 맞는 전용 영상과 첫 장면 이미지를 사용합니다. 도감·결과·홈·공유 소개에서 같은 공통 재생 UI를 사용합니다.

- 화면에 보이는 카드 앞면에서만 무음 반복 재생하며 화면 밖·뒷면·숨겨진 탭에서는 멈춥니다.
- 멈춤·재개 버튼을 제공하고, 동작 줄이기 설정에서는 자동 다운로드·재생을 하지 않습니다.
- 파일 실패 시 정적 이미지가 남으며, 미공개 캐릭터의 실루엣은 영상 파일을 요청하지 않습니다.
- 학생이 영상을 재생할 때 Gemini API를 호출하지 않습니다.

전체 파일의 프레임 디코딩·길이·해상도·프레임 수·무음 여부를 확인했습니다. 캐릭터별 10장면과 반복 경계를 육안으로 검토했습니다. 최종 영상의 첫·마지막 프레임 평균 RGB 차이는 255 단계 중 약 1.50~2.15였습니다. 로컬 미리보기에서 16개를 동시에 재생해 모두 두 번 이상 반복되는 것을 확인했고, 실제 공유 카드에서도 각 영상의 반복 경계를 두 번씩 확인했습니다. 실제 카드의 반복 경계 프레임 표시 간격은 약 33~83ms였습니다. 이 값은 16개 동시 재생 부하 검토의 값과 구분해 [전체 검사 기록](collection-generation.json)에 저장했습니다. 브라우저 페이지 오류와 모바일 화면 넘침은 없었습니다. 모바일 검토는 Chrome 화면 에뮬레이션입니다.

전체 캐릭터를 보기 위해 개인 도감 기록을 바꾸지 않고 로컬 검토 HTML을 만들 수 있습니다. HTML 파일을 브라우저로 열면 화면에 보이는 카드가 반복 재생되며, 기본 영상 컨트롤로 멈추거나 다시 재생할 수 있습니다.

영상·카드·수집 도감 Playwright 테스트는 데스크톱 35개와 모바일 화면 35개, 총 70개가 통과했습니다. 타입 검사, 변경 파일 ESLint와 Next.js 프로덕션 빌드도 통과했습니다. [최종 검증 기록](validation.json)을 함께 보관합니다.

```powershell
node scripts/preview-character-videos.mjs
# .artifacts/character-videos/review.html
```

공개된 캐릭터는 `/share/{code}`에서도 확인할 수 있습니다. 예: `/share/visual-solo-flexible`, `/share/tactile-team-flexible`, `/share/motion-team-flexible`.

## 재현

API 호출 없이 입력 이미지와 프롬프트만 준비합니다.

```powershell
node scripts/generate-character-videos.mjs
node scripts/generate-character-videos.mjs --code=tactile-team-flexible
```

유료 생성은 `--generate`를 명시해야 합니다. `.env.local`의 `GEMINI_API_KEY`를 사용합니다. 완료된 요청은 재사용하고, 기존 시도 기록이 실패·미확정이면 중복 비용을 막기 위해 멈춥니다. 요청 전에 기록을 새 파일로만 생성해 같은 캐릭터의 동시 실행도 방지합니다. 배치 예상 비용이 $18을 넘기 전에 다음 요청을 중단합니다. 이 값은 추정치 기준이며 공급자의 실제 청구 한도를 설정하는 기능은 아닙니다.

```powershell
node scripts/generate-character-videos.mjs --generate
```

저장된 원본을 다시 가공할 때는 API를 호출하지 않습니다. 로컬 FFmpeg·FFprobe가 필요합니다.

```powershell
node scripts/prepare-character-videos.mjs --code=motion-solo-flexible
node scripts/prepare-character-videos.mjs
```

루미의 원본과 v1/v2 제작 명령은 [기존 시안 기록](README.md#재현)에 보존했습니다.
