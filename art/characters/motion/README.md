# 공부캐 반복 영상 — 전체 제작과 루미 시안 기록

현재 16명 모두 8초 반복 영상을 표시합니다. 기존 15개는 마지막 정지 구간을 제거했고, 멜로는 두 팔로 수정한 원본으로 새 8초 영상을 제작했습니다. 잘못된 멜로 v1 영상은 표시에서 제외했습니다. [현재 상태와 최초 제작 기록](collection.md), [현재 영상 목록](collection-eight-second.json)을 함께 확인하세요.

루미의 10초 시안을 승인한 뒤 나머지 15명까지 제작해 초기에는 **16명 모두 전용 10초 영상**을 적용했습니다. 이후 멜로의 원본 오류를 발견해 수정 이미지로 교체했습니다. [전체 동작 설계·일괄 제작 기록·로컬 미리보기](collection.md), [전체 생성 비용·영상 목록](collection-generation.json)을 참고하세요. 아래는 처음 제작한 루미 시안의 상세 기록입니다.

## 동작 설계

루미는 혼자 차분하게 개념을 연결하는 부엉이입니다. 빠른 인사나 과장된 점프 대신, 노트의 개념 지도를 바라보며 생각을 확인하는 작은 동작으로 표현했습니다.

1. 원래 자세로 시작합니다.
2. 노트를 바라보고 천천히 눈을 한 번 깜빡입니다.
3. 연필을 든 날개를 살짝 들어 생각하는 시간을 가진 뒤, 작게 고개를 끄덕입니다.
4. 처음 자세로 돌아와 잠깐 유지합니다.

시작 이미지 한 장을 첫 프레임과 마지막 프레임으로 함께 지정했습니다. 고정 카메라와 일정한 크기·조명, 작은 움직임, 끝에서 속도를 줄이는 조건을 명시했습니다. 안경·깃털·옷·노트·도형을 유지하고, 글씨나 새 소품을 추가하지 않도록 했습니다. 정방향 동작 그대로 반복하며 역재생이나 크로스페이드를 사용하지 않았습니다.

## 제작과 비용

사용자가 10초로 늘려달라고 요청해 `gemini-omni-1.1-flash`로 새 영상을 **한 번** 생성했습니다. 기존 4초를 반복하거나 느리게 늘린 결과가 아닙니다. 1280×720, 10초, 24fps 원본에서 중앙 720×720 영역을 추출했습니다. 배경은 카드의 시각형 색상에 맞췄고, 브라우저용 영상의 오디오 트랙을 제거했습니다. H.264, yuv420p, faststart 형식이며 용량은 약 773 KiB입니다.

2026-10-01 [Google 공식 요금](https://ai.google.dev/gemini-api/docs/pricing#gemini-omni-flash)과 응답 사용량 기준 새 10초 시안의 예상 생성 비용은 **약 $1.03**입니다. 기존 4초 시안의 약 $0.42를 합하면 두 번의 루미 제작 비용은 약 $1.45입니다. Google의 실제 청구서를 확인한 값은 아닙니다. 생성 후 재생은 저장된 파일을 사용하며 Gemini API를 호출하지 않습니다.

전체 프레임 디코딩을 확인했습니다. 최적화된 영상의 첫 프레임과 마지막 프레임 사이 평균 RGB 차이는 255 단계 중 약 1.68입니다. 포즈와 구도를 육안으로 비교했습니다. Chrome 데스크톱과 모바일 화면 에뮬레이션에서 두 번 이상 반복되는 것을 확인했습니다. 반복 경계의 프레임 표시 간격은 약 33~50ms였으며 화면 넘침과 브라우저 오류는 없었습니다. 영상 브라우저 테스트 8개, 타입 검사, 변경 파일 ESLint와 프로덕션 빌드가 통과했습니다.

720p 영상 출력 비용 비교:

| 모델                  | 초당 출력 비용 | 8초 출력 비용 |
| --------------------- | -------------- | ------------- |
| Gemini Omni 1.1 Flash | 약 $0.10       | 약 $0.81      |
| Veo 3.1 Fast          | $0.10          | $0.80         |
| Veo 3.1 Standard      | $0.40          | $3.20         |
| Veo 3.1 Lite          | $0.05          | $0.40         |

Omni는 출력 영상 1초당 5,792토큰 × $17.50/백만 토큰으로 계산하며 입력 및 텍스트·생각 토큰 비용이 별도입니다. 위 값은 영상 출력만 비교합니다. Veo는 오디오 포함 요금입니다. 현재 [Veo 길이 사양](https://ai.google.dev/gemini-api/docs/veo#model-features)은 한 번 생성 시 4·6·8초이므로 비교 예시는 8초로 맞췄습니다. [공식 요금](https://ai.google.dev/gemini-api/docs/pricing#veo-3.1).

## 웹 적용

`CharacterCard`에서 각 캐릭터의 전용 영상을 표시합니다. 공개된 카드·결과·홈·친구 공유 화면에서 같은 자산을 사용합니다. 미공개 실루엣은 기존 이미지로 유지하며 영상을 요청하지 않습니다. 자산 목록은 `src/lib/character-motions.ts`, 공통 재생 UI는 `src/components/character-motion.tsx`에서 관리합니다.

- 화면에 보이는 카드 앞면에서만 무음 반복 재생합니다.
- 멈춤·재개 버튼을 제공하고, 뒷면·화면 밖·숨겨진 탭에서는 일시 정지합니다.
- 시스템의 동작 줄이기 설정에서는 정적 이미지만 표시하고 자동으로 영상을 내려받지 않습니다. 사용자가 재생 버튼을 누르면 시작합니다.
- 자동 재생이 차단되면 재생 버튼으로 시작할 수 있습니다. 파일 로딩 실패 시 정적 이미지가 남습니다.
- 영상 파일에는 Gemini API 키가 없으며 생성 스크립트만 `.env.local`의 키를 사용합니다.

## 재현

이미지 준비만 실행할 때는 API를 호출하지 않습니다.

```powershell
node scripts/generate-lumi-video.mjs --version=v2
```

기본 버전은 현재 10초 시안인 v2입니다. `--version=v1`은 보존된 4초 시안에 해당합니다. 실제 유료 생성은 `--generate`를 붙였을 때만 한 번 실행됩니다. 해당 버전의 `generation.json` 또는 최종 MP4가 있으면 재호출을 막습니다. 요청 기록을 새 파일로만 만들 수 있게 해 동시 실행도 방지합니다. 실패·시간 초과 후에도 자동 재시도하지 않으며, 중복 비용을 피하기 위해 기존 요청의 상태를 먼저 확인해야 합니다.

```powershell
node scripts/generate-lumi-video.mjs --version=v2 --generate
```

저장된 원본을 카드용 파일로 가공하는 아래 명령에는 API 비용이 없습니다. 로컬 FFmpeg와 FFprobe가 필요합니다.

```powershell
node scripts/prepare-lumi-video.mjs --version=v2
```

원본 MP4와 입력 이미지는 v1의 경우 `.artifacts/lumi-video/`, v2의 경우 `.artifacts/lumi-video-v2/`에 보관합니다. 프롬프트·생성 기록·가공 스크립트·최종 카드용 파일은 저장소에 포함합니다.
