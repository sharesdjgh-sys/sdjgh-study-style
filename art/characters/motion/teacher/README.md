# 토리 선생님 히어로 인사 영상

8초 영상 두 편을 각각 생성한 뒤 순서대로 이어 붙인 16초 한국어 인사 영상입니다. 기존 토리 선생님 이미지를 기준으로 제작했습니다. 현재 히어로는 기존 랜덤 실루엣 카드를 유지하며, 토리는 제목 아래 ‘토리 선생님’ 안내 문구 왼쪽의 작은 가이드로 표시합니다. 16초 영상은 보관용이며 현재 히어로에서 표시하거나 로드하지 않습니다. 안내자는 두 번째 8초 영상에서 배경을 제거한 192px 투명 Animated WebP(`teacher-tori-guide-transparent.webp`)를 버튼 없이 무한 반복합니다. 중간 가공용 256px MP4는 보관합니다.

최종 WebP는 8초, 무한 반복(loop=0), 716,274바이트입니다. 16fps 기준 128개 입력 프레임 중 동일한 프레임을 인코더가 병합해 실제 저장 프레임은 127개이며 전체 재생 시간은 8초로 유지됩니다. 모든 프레임의 모서리 알파값 0과 전체 디코딩을 검증했습니다. 시스템의 동작 줄이기 설정에서는 정적 포스터를 사용합니다.

## 제작 및 확인

2026-10-02 Gemini Omni 1.1 Flash로 한국어 발화와 입 모양을 함께 생성했습니다. 기존 Gemini API 연결을 사용했습니다. 첫 장면은 네트워크 접근 제한 1회, HTTP 400 거절 1회 후 프레임 지정을 단순화해 생성됐습니다. 두 번째 장면은 첫 API 요청으로 생성됐습니다. 성공 응답 두 건의 사용량은 각 generation.json에 보존했습니다. 실패 기록은 로컬 `.artifacts/teacher-video-v1/part-1/`에 보존합니다. 자동 유료 재시도는 하지 않습니다.

720p 가로 원본의 중앙을 720×720으로 잘랐습니다. 24fps H.264/AAC, faststart, 대사 음량 정규화를 적용했습니다. 길이는 각각 8초이며 반복 복제나 역재생으로 늘리지 않았습니다. 프레임 정규화 시 필요한 마지막 프레임 유지 구간은 1프레임 내외입니다. 영상 전체 디코딩과 1초 간격 장면을 확인했습니다.

음성 검수는 로컬 Whisper base로 수행했습니다. 두 장면의 인식 결과가 의도한 대사와 일치했습니다. 이는 자동 음성 인식 검수이며 사람의 청취 검수는 아닙니다. 자막은 문장 단위로 배치했으며 단어별 강제 정렬은 하지 않았습니다. 외부 Gemini 재업로드 검수는 승인 검토에서 거절되어 수행하지 않았습니다. 영상·음성은 로컬 검수 과정에서 외부로 전송하지 않았습니다.

## 이전 영상 시안의 재생 동작 (현재 히어로에서는 미사용)

- 화면에 보일 때 무음 반복 재생. 화면 밖이나 비활성 탭에서 일시 정지.
- ‘처음부터 목소리 듣기’를 누르면 0초부터 소리를 켜고 한 번 재생.
- 재생·멈춤, 소리 끄기, 한국어 자막과 펼쳐 볼 수 있는 인사말 제공.
- 동작 줄이기에서는 사용자가 누르기 전 영상 소스를 로드하지 않음.
- 영상 오류 시 정적 포스터와 인사말 제공.
- 재생은 저장된 파일만 사용하며 생성 API를 호출하지 않음.

기존 원본을 다시 가공하는 무료 로컬 명령: `node scripts/prepare-teacher-video.mjs`.
유료 생성 스크립트는 `node scripts/generate-teacher-video.mjs --part=1 --generate` 형태이지만 기존 시도가 있으면 중복 요청을 차단합니다. `--generate`를 생략하면 이미지와 프롬프트만 준비합니다.

참고: [Google 공식 영상 생성 문서](https://ai.google.dev/gemini-api/docs/omni).
