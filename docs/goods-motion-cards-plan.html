각자의 이야기가 움직이는
16장의 새로운 순간

공부캐의 성격이 드러나는 행동 하나와 작은 발견 하나를 담은 움직이는 이야기. 기존 128장과 별개의 신규 16장으로 구성한다.

캐릭터당 1장해금 3별10초 기준 · 8~12초세로 2:3기존 128장 + 신규 16장

기획 초안 · 영상 미제작 · 서비스 미반영

소장과 구분

해당 공부캐를 계정 도감에 소장한 사용자가 별 3개로 영구 해금. 기존 1별·2별 굿즈 구매는 선행 조건으로 두지 않는다. 재생과 재저장에는 추가 별을 쓰지 않는다.

분류명은 움직이는 스페셜 카드를 권장합니다. 기존 특별 의상 카드 · 2별과 이름·재생 표시·가격으로 구분합니다. 추가 후 캐릭터당 9장, 전체 144장입니다.

보는 경험

목록은 정지 표지와 재생 표시. 해금 후 상세 화면에서 영상 한 번을 재생하고 마지막 장면에 머문다. 다시 재생 버튼 제공. 자동 반복은 기본으로 켜지 않는다.

서사가 완성되는 영상을 억지로 되감지 않는다. 자연 순환이 가능한 장면만 별도 반복 버전으로 검토한다.

첫 버전은 무음으로도 이야기가 완결되게 제작. 대사·립싱크·음악 의존 연출은 제외한다.

그림과 움직임

검토 완료된 공부캐의 얼굴·털색·신체 비율을 유지하는 부드러운 입체 일러스트. 캐릭터별 배경·소품·동작을 구분한다. 카메라는 고정 또는 느린 전진 한 가지로 제한한다. 영상 안에 제목·자막·UI를 굽지 않는다.

아래 기존 굿즈는 얼굴·의상·세계관 참고 자료이며 최종 영상이나 신규 표지가 아니다. 영상용 시작 프레임은 동작과 여백에 맞게 새로 구성한다.

먼저 만들 3장

  1. 루미: 얼굴과 도구를 유지하면서 빛의 연결이 자연스러운지 확인합니다.
  2. 멜로: 가까운 표정 연기, 김의 변화, 정확히 두 앞발을 유지하는지 확인합니다.
  3. 블록: 두 캐릭터의 역할, 물체 접촉, 조립의 원인과 결과를 검증합니다.

세 장의 시작 프레임을 먼저 검토한 뒤 10초 시범 영상을 만듭니다. 얼굴이 바뀌거나 손이 늘어나는 문제, 소품이 갑자기 사라지는 문제를 통과해야 나머지 13종으로 확대합니다.

  • 표지와 영상의 같은 장면을 맞춰 해금 전후 캐릭터가 달라 보이지 않게 합니다. 썸네일에는 영상이 아닌 정지 표지만 사용합니다.

향후 구현 범위와 아직 확정하지 않은 사항

영상 생성 도구·모델·비용·실제 출력 가능 길이는 아직 선정하거나 검증하지 않았습니다. 시범 제작 전에 확인합니다. 이번 문서는 콘셉트와 장면 기획이며 영상을 이미 제작했다는 의미가 아닙니다.

카탈로그에 신규 kind(제안: motion), mediaType, video, poster, duration, cost 필드를 추가하고 기존 소장 ID는 유지합니다. 신규 ID는 캐릭터 코드별 --motion-01을 제안합니다. 프런트엔드 goodsPrice는 현재 일상 1별·그 외 2별 구조이므로 3별을 명시하도록 수정해야 합니다.

현재 db/008_goods_stars.sql의 goods_catalog는 daily/special만 허용합니다. 새 마이그레이션으로 motion 허용 및 신규 16개 가격 3별 데이터를 추가해야 합니다. 기존 마이그레이션을 고쳐 재실행하지 않습니다. 기존 redeem_goods의 소장·잔액·중복 차감 방지 흐름을 유지하고 서버에서도 가격을 검증합니다.

소장 전에는 봉인과 설명만 노출하고 영상 URL·전체 표지를 전송하지 않는 현재 원칙을 유지합니다. 정적 공개 경로만으로 소유권 제한을 구현하지 말고, 다운로드·재생 요청에서 소유권을 확인하는 전달 방식을 검토합니다.

해금 연출이 끝난 뒤 영상을 재생하며 두 연출을 겹치지 않습니다. 모션 줄이기 설정에서는 정지 표지와 명시적인 재생 버튼을 제공합니다. 재생 오류는 다시 시도로 처리하고 교환 요청을 다시 보내지 않습니다. 목록 일괄 자동재생은 하지 않습니다.
